## 六、多账号凭证支持（v0.3.0 主线）

> **诉求**：所有**需要手填 Key** 的平台都支持多账号（同一平台可保存 / 展示多个账号的凭证）。
> **例外**：**Trae 积分**不需要多账号 —— 它的凭证是本机 Trae CN 登录态现场解密出来的，天然只有一份。

### 数据模型：把「账号」提升为一等公民

| 层 | 现状 | 目标 |
|---|---|---|
| 场景标识 | `active` = 数据源 id（如 `aliyun`） | `active` = **账号 id**（全局唯一，形如 `aliyun:1`） |
| 账号结构 | 无 | `{ id, sourceId, label }`（**不含密钥值**，可落盘），`label` 用户可改，默认「默认账号」 |
| 凭证文件 | `sources{ sourceId: {k:v} }` + `savedIds[sourceId]` | `accounts[{id,sourceId,label}]` + `sources{ accountId: {k:v} }` + `savedIds[accountId]`（version 3） |
| 钥匙串 account 键 | `sourceId`（如 `aliyun`） | **带前缀的账号 id**（如 `a:aliyun:1`），与旧条目隔离、不碰撞 |
| 刷新间隔 | `refresh{ sourceId: 秒 }` | `refresh{ accountId: 秒 }` |
| 上次成功数据 | `lastGoodViews[sourceId]` | `lastGoodViews[accountId]` |
| Tab | 按平台（已配置的平台各一个） | **按账号**，显示 `${平台名} · ${账号名}`（如「阿里云 · 主号」） |

### 实现步骤（全部完成）
